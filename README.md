# Trade Academy

Página web estática para promocionar y vender cursos de trading.  
Este proyecto fue desarrollado para el Parcial 1 de Programación con Tecnologías Web.

## Integrantes

- Tu nombre
- Nombre de tu compañero

## Descripción

Trade Academy permite consultar cursos de trading disponibles e inscribirse a uno de ellos mediante un formulario.  
El proyecto usa HTML, CSS y JavaScript, además de una API simulada en `mockApi.js`.
